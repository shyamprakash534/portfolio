# Syam Prakash — 3D Developer Portfolio

React + Vite + React Three Fiber portfolio with a dark, modern visual system.

## Run locally

```bash
npm install
npm run dev
```

## Add your GLB assets

Copy these files into `public/models/`:

- `avatar.glb`
- `laptop.glb`

The hero avatar subtly follows the mouse. The laptop animation responds to scroll progress as the experience section enters the viewport. Skills use gentle floating motion and hover scaling.

## Customize

Main content is in `src/main.jsx` near the `profile`, `projects`, and `skills` constants.
